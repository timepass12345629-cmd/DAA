## 2. Module Inventory and Purpose

| Directory / Module | Purpose | Language / Tech | Primary Dependencies |
| :--- | :--- | :--- | :--- |
| `ringscope/graph.py` | Transaction graph abstraction wrapping NetworkX simple graphs while preserving transaction volume, amounts, timestamps, and skipping self-loops. | Python 3.12 | NetworkX |
| `ringscope/storage.py` | SQLite database schema (`graphs`, `accounts`, `transactions`) and persistence operations. | Python 3.12 | sqlite3 |
| `ringscope/algorithms/dinic.py` | Standalone Dinic maximum-flow implementation with BFS level graph, DFS blocking flow, and source-side cut extraction. | Python 3.12 | Standard library (collections) |
| `ringscope/algorithms/goldberg.py` | Goldberg's exact densest subgraph solver via binary search over parameter $g$ in an edge-node bipartite flow network. | Python 3.12 | `dinic.py`, NetworkX |
| `ringscope/algorithms/greedy_peeling.py` | Charikar's degree-peeling algorithm (2-approximation) with $O((m+n)\log n)$ heap-based peeling. | Python 3.12 | Standard library (heapq) |
| `ringscope/algorithms/greedy_plus_plus.py` | Multi-pass load-peeling algorithm (Boob et al., 2020) maintaining cumulative vertex loads. | Python 3.12 | Standard library (heapq) |
| `ringscope/algorithms/cycle_detection.py` | Directed elementary cycle detection using Johnson's algorithm with transaction domain filters. | Python 3.12 | NetworkX |
| `ringscope/streaming.py` | Transaction event generator and stream batch simulator with planted ring injection. | Python 3.12 | Standard library (random) |
| `ringscope/streaming_maintainer.py` | Streaming densest subgraph maintainers: Mode A (Full), Mode B (Warm-Start), Mode C (Heuristic). | Python 3.12 | `goldberg.py`, `greedy_peeling.py` |
| `ringscope/service.py` | `BackendService` singleton managing in-memory active graphs, streaming sessions, and async algorithm execution. | Python 3.12 | asyncio |
| `ringscope/api_v1.py` | REST API routes exposing graph management, algorithms, streaming, and experiments. | Python 3.12 | FastAPI, Uvicorn |
| `ringscope/models_v1.py` | Strict Pydantic v2 data transfer schemas for all request/response payloads. | Python 3.12 | Pydantic v2 |
| `ringscope/experiment_harness.py` | Execution harness for running parameter sweeps, collecting metrics, and writing CSV/JSON exports. | Python 3.12 | Standard library |
| `frontend/src/` | Interactive Single-Page Application providing graph visualization, algorithm comparison, and streaming controls. | TypeScript | React 19, Vite, Cytoscape.js, Recharts, Tailwind CSS |

## 3. System Entry Points

### 3.1 Backend Entry Point
- **Module:** `ringscope.api_v1:app`
- **Start Command:**
  ```powershell
  .venv\Scripts\python.exe -m uvicorn ringscope.api_v1:app --host 127.0.0.1 --port 8000 --reload
  ```
- **Interactive OpenAPI Documentation:** Available at `http://127.0.0.1:8000/docs` or `http://127.0.0.1:8000/redoc`.

### 3.2 Frontend Entry Point
- **Root File:** `frontend/index.html` -> `frontend/src/main.tsx`
- **Development Server:**
  ```powershell
  cd frontend
  npm run dev
  ```
  Runs Vite dev server on `http://localhost:5173` (proxies `/api/v1` to `http://127.0.0.1:8000`).
- **Production Build:**
  ```powershell
  cd frontend
  npm run build
  ```
  Generates static distribution in `frontend/dist/`.

### 3.3 Experiment Suite Entry Point
- **Primary Script:** `scripts/run_experiments.py`
- **Execution Command:**
  ```powershell
  .venv\Scripts\python.exe scripts/run_experiments.py --exp all --output-dir experiments_output/reproduced
  ```
- Individual experiments can be executed via `--exp 1` through `--exp 7`.

### 3.4 Test Suite Entry Points
- **Backend Tests:**
  ```powershell
  .venv\Scripts\python.exe -m pytest tests/ -v
  ```
- **Frontend Tests:**
  ```powershell
  cd frontend
  npm run test
  ```
